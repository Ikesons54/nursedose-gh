# NurseDose GH

*Understand drug calculations. Don't cram them.*

A mobile-first, offline-ready web app (PWA) that teaches drug dose calculations step by step to nursing students in Ghana.

Powered by FWXplus.

## Status
Day 1 of the 8-day MVP plan: the live page is up. See `docs/ROADMAP.md`.

## Run it
Open `index.html`, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## MVP scope
Dose calculator, step-by-step tutor, preloaded Ghana exam-style questions (tablets, syrups, injections), offline support.

## Safety
For learning only. Doses must be checked with a tutor and hospital protocol.
